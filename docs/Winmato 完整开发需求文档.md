## 0\. 文档说明

本文档为 **Winmato** 唯一正式开发规范，专为 AI 编程工具直接生成代码使用，无模糊需求、无冗余功能、无需二次解读。所有开发必须严格遵循本文档规则，禁止私自新增功能、交互、UI 元素。

**版本**：2.2（T 方案修订——边框永存 / 任务栏厚度自适应画布 / 待填充待机 / 暂停符号强化 / 应用图标资产嵌入 / 更名 Winmato）

**项目名称**：Winmato（Win + Tomato；v2.1 由 Barmato 更名——Bar（任务栏）语义随 T 方案消失，载体变为 Windows 托盘图标）

**更名说明**：原名 Barmato = Bar + Tomato，其中 Bar 指任务栏，是旧方案（任务栏染色 / 开始按钮覆盖）的载体；T 方案后唯一可视化表面是 Windows 托盘图标，故一对一替换 Bar → Win，保留 -mato。可执行文件、配置目录、互斥量、窗口类名等全部标识同步更名。

**产品最终形态**：极简环境式番茄钟（正式定稿，不可修改）

**设计核心依据**：《软件设计的哲学（第二版）》全套核心准则

**核心设计纲领（强制置顶，所有开发优先级最高）**：

- 严格践行**深模块、浅接口**

- **最小化用户状态与交互**，消除一切不必要操作

- 所有 Windows 系统层级复杂逻辑、边界问题全部封装在程序内部，对用户完全透明

- 用户仅感知极简行为，零学习成本、零心智负担

- 产品定位：**纯环境感知型番茄钟**，绝对不做仪表盘、不做操作控制器

- 核心使命：服务深度专注（工作、阅读、创作、编程），尽可能零抢夺用户注意力

## 1\. 产品核心定位与底层哲学（不可违背）

### 1\.1 真实核心目标

不做计时工具、不做效率管控工具、不做任务管理工具。将**系统托盘图标本身**变成唯一的环境反馈媒介：**四格阵表达阶段（慢变量）、格内灌注表达进度（快变量）、格位空间编码表达番茄序号**，提供**余光可感知、无干扰、无打断**的番茄周期环境反馈，辅助用户维持长时间深度专注流。指示器不新增任何悬浮实体、不侵入任务栏、不染色系统元素——托盘图标即环境本身。

### 1\.2 严格反目标（永久禁止功能蠕变）

以下功能**绝对禁止开发、绝对禁止后续迭代添加**，遵循「减法优于加法」的设计哲学：

- ❌ 禁止显示任何数字、文字、剩余时间、进度百分比、统计数据

- ❌ 禁止任何弹窗、桌面通知、提示音效、阶段提醒

- ❌ 禁止跳过、重置、废弃、手动切换番茄阶段的任何交互

- ❌ 禁止开发任何图形化设置窗口、可视化参数配置页面

- ❌ 禁止悬浮窗、主程序窗口、任何桌面悬浮控件

- ❌ 禁止数据统计、历史记录、日志留存、数据导出

- ❌ 禁止多模式切换、自定义交互逻辑

- ❌ 禁止对任务栏、桌面、系统元素做任何染色、叠加、遮挡、注入

### 1\.3 设计哲学落地细则

- **深模块浅接口**：用户交互接口极简单一，计时状态、动画状态、像素渲染、异常处理等所有复杂逻辑全部内埋

- **消除特殊场景**：主动砍掉高复杂度、低收益的功能，减少边界 case，不为小众场景冗余编码

- **最小意外原则**：所有视觉变化、交互反馈符合直觉，无突兀、无未知行为

- **优雅降级优先**：系统异常、适配失败时，静默恢复默认状态，绝不弹窗报错、不打扰用户专注

- **职责隔离**：提醒、统计、自定义参数等功能交由其他软件，Winmato 只专注「环境视觉反馈」单一核心职责

- **第一性原理载体选择**：托盘图标是应用自有表面，不侵入系统元素、不持续跟踪外部几何（仅启动时只读一次任务栏厚度用于画布定尺寸，失败静默回退）、零 alpha 叠加限制，色彩完全自控

## 2\. 核心业务规则（固定逻辑，默认不可改）

### 2\.1 固定番茄大周期（唯一工作模型）

一个完整闭环大周期固定为 **4 次专注番茄 + 对应短休 + 最终长休**，时序固定、顺序不可乱序、不可跳过：

1. 专注阶段：25min

2. 短休阶段：5min

3. 专注阶段：25min

4. 短休阶段：5min

5. 专注阶段：25min

6. 短休阶段：5min

7. 专注阶段：25min

8. 长休阶段：20min

9. 周期结束：自动回归**待机状态**，托盘图标为四格空心「**待填充**」轮廓（完成与否不产生视觉特殊分支，消除特殊场景；tooltip 同步提示「本轮已完成」，完成瞬间有一次 2.5s 边界脉冲闪光）；新周期**仍由用户左键手动触发**（见 §3.1），不自动开始——尊重用户节奏主权，符合番茄工作法正统

### 2\.2 高级用户逃逸口（无UI、不污染普通体验）

仅提供本地 JSON 配置文件（路径：`%APPDATA%\Winmato\config.json`），支持发烧友手动修改：各阶段时长、阶段配色。

强制规则：**无任何图形化配置入口**，普通用户完全无感知；配置文件损坏/缺失时，静默回退默认参数，不报错、不弹窗、不写回。

## 3\. 全局用户交互规范（全网最简接口）

整个程序**仅 1 种用户交互动作**，无快捷键、无多余操作，彻底实现浅接口。

### 3\.1 唯一核心交互：左键点击系统托盘图标

交互逻辑（闭环无歧义）：

- 待机状态 → 左键点击托盘图标 → 启动完整番茄大周期，进入首个专注阶段

- 运行状态 → 左键点击托盘图标 → 暂停当前周期，时间冻结、进度静止

- 暂停状态（专注/短休）→ 左键点击托盘图标 → 继续当前周期，进度、时间正常推进

- **暂停状态（长休）→ 左键点击托盘图标 → 收束本轮**，回归四格待填充待机态（tooltip「本轮已完成」）；下一次点击才启动全新周期。设计依据：长休是收尾阶段，4 枚番茄已全部获得，恢复一段收尾冷却毫无收益——用户在长休暂停后的再点击即表达「休息结束」；待机不自动开新周期（保持「启动永远显式」）。至此，**一切结束路径（自然走完长休 / 长休暂停后收束）都收束到同一个待填充待机态，点击语义由当前状态唯一决定，闭环无歧义**

设计依据（文档 §1.3 深模块浅接口 / 最小意外原则）：
托盘图标是 Windows 中**最稳定的不变量**——始终存在、位置固定、不受任务栏布局（居中/靠左/自动隐藏）、Windows 版本更新、多屏配置等任何因素影响。将交互入口建立在不变量上，消除了任务栏空白区检测、分层窗口几何、多屏适配等脆弱启发式逻辑，使代码量与边界 case 大幅缩减。T 方案进一步将**可视化表面与交互入口合二为一**——同一颗托盘图标既是输入（点击）又是输出（渲染）；仅启动时只读一次任务栏厚度以最大化图标尺寸，失败静默回退，不持续依赖外部几何。

### 3\.2 唯一附属入口：系统托盘图标右键菜单

托盘菜单**仅保留唯一选项：退出程序**。

禁止添加：设置、重置、刷新、帮助、关于、切换模式等任何多余菜单。

周期放弃规则：用户若想废弃当前番茄周期，唯一方式为退出程序，重启自动回归待机状态（刻意牺牲少量便利，换取极简状态机、零边界 bug）。

## 4\. 视觉渲染规范（环境式无感设计）

### 4\.1 渲染底层原理（固定技术方案：托盘图标四格可视化）

**T 方案——托盘图标即唯一可视化表面**：托盘图标画布尺寸**自适应任务栏厚度**——应用的全部价值依赖视觉体验，图标应在任务栏内尽可能大。启动时查询主任务栏窗口（`FindWindowW("Shell_TrayWnd")` + `GetWindowRect`）矩形，取短边（底/顶部任务栏短边 = 高度，左/右侧 = 宽度，方向无关）减去双侧 4px 留白（图标边长 = 厚度 − 8px）作为画布边长；查询失败、窗口缺失、自动隐藏态厚度异常（< 16px）时静默回退系统小图标标准尺寸 `GetSystemMetrics(SM_CXSMICON)`。几何按比例参数化：方格 = size/3、间距 = max(size/16, 1)、偏移 = (size − 2·方格 − 间距) / 2 居中；画布 < 16px 时渲染全透明（极端兜底）。尺寸只在启动时查询一次，不持续跟踪任务栏变化。四格与四个专注番茄一一同构，格位即番茄序，格内灌注高度即当前阶段进度，色相即阶段属性。

渲染由纯函数完成：输入 (Snapshot + Palette + Instant) → 输出 RGBA 像素缓冲 → 构造 `tray_icon::Icon`。无系统窗口、无分层窗口、无 softbuffer、无任务栏染色、无 alpha 叠加——色彩完全自控，不受任何系统元素限制。

**T 方案取代 D/C 方案的理由（第一性原理 + 极简主义）**：

- 托盘图标是应用自有表面，不侵入系统元素（无任务栏染色、无分层窗口注入）

- 无持续几何跟踪（仅启动时只读一次任务栏厚度定尺寸，失败回退系统小图标标准；无任务栏位置/DPI 变化监听、无多屏适配、无资源管理器重启重建）

- 纯计算渲染（Snapshot → RGBA 像素），完全可单元测试，无系统状态耦合

- 色彩完全自控，不受 alpha 叠加、WCAG 对比度钳制等限制，小尺寸下可适当提高饱和度保持辨识度

- 交互入口与可视化表面合二为一，状态机最小化

**载体稳定性保障**：

- 托盘图标始终存在于通知区，不受任务栏布局、Windows 版本、多屏配置影响

- Windows 11 默认将新通知图标放入隐藏溢出区（chevron 折叠区），程序启动时通过注册表 `HKCU\Control Panel\NotifyIconSettings\<id>` 的 `IsPromoted` 值置 1，将图标提升到任务栏可见区；提升失败时静默降级——图标仍可用，只是留在溢出区（文档 §7 优雅降级）

### 4\.2 状态与视觉映射（极简配色、低干扰）

全程无文字、无数字、无叠加图层，仅靠「四格阵 + 阶段色相 + 灌注高度 + 空间编码 + 边界脉冲 + 暂停呼吸」区分所有状态，余光可识别，不抢夺注意力。

**四格语义（与 S 方案一致，载体不同）**：

- **专注 N**（N = 1..=4）：格 1..N−1 实心专注色（已获得的番茄），第 N 格从底部灌注专注色，灌注高度 = 当前专注阶段进度

- **短休 N**：格 1..N 实心专注色（第 N 格是刚完成的番茄），第 N 格从底部灌注短休色，灌注高度 = 当前短休阶段进度

- **长休**（第 4 番茄后）：格 1..4 全部实心专注色，第 4 格从底部灌注长休色，灌注高度 = 当前长休阶段进度

- **待机**：四格全部为空心灰色轮廓（1px 边框），无填充——低存在感但恒可见，保障 §3.1 交互入口可发现性；**完成与否不改变待机视觉**（消除特殊场景），完成信息走 tooltip 通道
- **未来格**（当前番茄序之后的格）：无底色无灌注时渲染为浅灰空心轮廓

|程序状态|托盘图标视觉表现（默认配色）|进度行为|格位编码|
|---|---|---|---|
|待机|四格空心灰色轮廓（#6E6E6E），无填充|无进度|无格位亮起|
|待机·本轮已完成|四格空心灰色轮廓（**同普通待机**，零特殊分支）|无进度|无格位亮起|
|运行-专注阶段 N|格 1..N−1 实心深绿，第 N 格从底部灌注深绿|灌注高度 = 本阶段进度（25min 灌满整格）|前 N−1 格实心 + 第 N 格灌注|
|运行-短休阶段 N|格 1..N 实心深绿，第 N 格从底部灌注薄荷青|灌注高度 = 本阶段进度（5min 灌满整格）|前 N 格实心 + 第 N 格灌注|
|运行-长休阶段|格 1..4 全部实心深绿，第 4 格从底部灌注天蓝|灌注高度 = 本阶段进度（20min 灌满整格）|4 格全实心 + 第 4 格灌注|
|暂停（任意阶段）|保留当前所有色相与格位状态，整体亮度降低 50%（仅变暗、不换色），叠加约 12s 周期的 ±10% 明度慢呼吸；**居中叠加放大暂停符号 ❚❚**（当前阶段色、恒满不透明——暂停态唯一满亮度元素，不参与降亮与呼吸）|进度完全静止、时间冻结|格位同运行态，但随整体呼吸|

> **暂停符号设计依据**：通用媒体暂停语义（❚❚），非文字、不破坏四格几何语言；几何按画布比例（条宽 = size/10、条高 = size/2、条间距 = size/10）。**恒满不透明 + 阶段色**是与降亮格阵形成对比的关键——若符号参与整体降亮（与格阵同 alpha、同灰色），则灰叠灰不可辨；阶段色满亮度使符号在明/暗任务栏主题下均为第一可读元素。不使用"Z"等字母（文字语义、非通用、小画布字形无法清晰渲染）。

**默认配色（出厂参数）**：

|色相|Hex|RGB|语义|
|---|---|---|---|
|Focus 专注|#2D8C53|(45, 140, 83)|深绿 H145 S47% L33%——深度专注|
|ShortBreak 短休|#47B3B3|(71, 179, 179)|薄荷青 H175 S45% L50%——短暂休息|
|LongBreak 长休|#5585C8|(85, 133, 200)|天蓝 H210 S40% L55%——长休息|
|IDLE_OUTLINE 待机轮廓|#6E6E6E|(110, 110, 110)|中性暗灰——低存在感但恒可见|

T 方案不再 alpha 叠加于系统元素，色彩自由度提升，配色饱和度较 D/C 方案适当提高，以在小尺寸画布中保持辨识度。用户自定义配色（§2.2）直接生效，无需 WCAG 钳制。

**空间编码细则（文档 §1.2 反目标：禁止数字，格位必须纯空间编码）**：

- 四格按 2×2 排列（左上、右上、左下、右下），分别对应第 1、2、3、4 个专注番茄

- 已完成番茄 = 实心格；当前番茄 = 底部灌注格；未来番茄 = 空心轮廓格

- 任何阶段均不显示具体数字，只通过「前 N 格实心 + 第 N 格灌注」的空间模式传递「当前处于第 N 个专注单元」的信息

- **边框永存不变量**：每格 1px 轮廓为结构层，底色/灌注为内容层，二者正交——实心与灌注仅画在 inset 1px 的内区，任何填充状态下边框不被吞没，保证空心 / 实心 / 灌注三态在小画布上始终可分辨

### 4\.3 视觉设计强制规则（动画常量）

所有动画常量为编译期固定值，禁止运行期可调：

|常量|值|语义|
|---|---|---|
|TRANSITION_SECS|0.6|阶段切换色相平滑插值时长|
|PULSE_SECS|2.5|边界脉冲单次呼吸时长|
|PULSE_PEAK|0.15|边界脉冲明度峰值（+15%）|
|BREATH_PERIOD_SECS|12.0|暂停呼吸周期|
|BREATH_AMPLITUDE|0.10|暂停呼吸明度幅度（±10%）|
|PAUSE_DIM|0.5|暂停整体降亮系数（降至 50%）|

强制规则：

- 所有配色统一中低饱和度，杜绝高饱和刺眼颜色，适配长时间专注场景

- 暂停状态仅做亮度修饰（整体降亮 50%）+ 恒满不透明阶段色暂停符号 ❚❚ + 约 12s 周期、±10% 明度的慢呼吸，三重表达降低用户记忆负担，不新增色相体系

- 阶段切换时，灌注色相经 0.6s 线性插值（lerp）平滑过渡，无闪烁、无突变、无弹窗提示

- **边界脉冲仪式**：每当阶段切换（专注→短休、短休→专注、专注→长休）以及周期启动（待机→首个专注）瞬间，整体执行一次约 2.5s 的明度慢脉冲（明度提亮约 15% 再回落），如同一次呼吸。每阶段仅触发一次，不循环、不持续，仅用于标记事件边界。边界事件由状态机暴露的单调递增 `stage_seq` 探测

- 暂停呼吸与边界脉冲均为低频动画，重绘帧率按需协商（见 §6.4），不引入持续高帧率开销

- 待机状态复位全部动画状态，渲染为四格空心轮廓，极致轻量化

## 5\. 程序状态机设计（最小状态空间）

全程仅 5 种顶层状态，无冗余状态、无模糊状态、无交叉边界状态，彻底减少 bug 来源：

1. 待机状态（默认初始、周期结束自动回归）

2. 运行-专注状态

3. 运行-短休状态

4. 运行-长休状态

5. 暂停状态（叠加态，依附于以上 3 种运行状态，不独立新增周期阶段）

状态流转逻辑：单向闭环、无跳跃、无回溯，严格按照固定番茄周期自动推进，禁止手动跨阶段跳转。唯一例外：**长休暂停后的点击 = 收束本轮**（§3.1）——它不是跨阶段跳转，而是收尾阶段的自然出口。阶段边界通过单调递增的 `stage_seq` 暴露给渲染层，作为边界脉冲触发源（§4.3）；暂停不推进 `stage_seq`（暂停不是阶段边界）。周期**自然走完**或**长休暂停后收束**均回归待机并携带完成标记（`completed`，§4.2）——二者都发生在 4 枚番茄全部收获之后，「完成 ⟺ 收获 4 枚番茄」语义严格成立；左键启动新周期即清除。**点击路径不存在中途放弃**（唯一放弃方式是退出进程，§3.2）。

## 6\. 内部模块架构（深模块落地，复杂全内埋）

所有内部模块逻辑、系统适配、动画状态、像素渲染全部封装，用户完全无感知，对外仅暴露唯一交互接口。模块彻底解耦：业务逻辑（cycle）零系统依赖、可独立单元测试；渲染（icon）为纯函数；色彩（colors）为纯计算；配置（config）只读加载；主线（main）仅做粘合。

### 6\.1 周期状态机模块（cycle.rs——纯业务、跨平台、可单元测试）

- 独立维护番茄周期时序（8 阶段固定布局）、计时逻辑、状态流转、暂停/继续标记

- 零 Windows API 依赖，纯逻辑计算，无 UI 耦合，可独立单元测试

- 对外暴露 `Snapshot` 快照：当前阶段（Phase）、当前阶段进度（phase_progress, 0.0..=1.0）、第几个专注番茄（pomodoro_index, 1..=4）、阶段序号（stage_seq, 单调递增）、完成标记（completed, 4 枚番茄全部收获后置位——自然走完或长休收束；新周期启动清除；运行态恒 false）、暂停标记、待机标记——这是渲染层与主线唯一需要的信息

- 自动处理阶段切换、周期收尾、待机回归逻辑；单次 tick 跨越多阶段（如系统休眠恢复）时循环结算到位

- 零时长配置不 panic、不除零（配置层已拦截，状态机兜底）

### 6\.2 托盘图标渲染模块（icon.rs——纯函数渲染器）

- 渲染器封装全部动画状态（色相过渡、边界脉冲、暂停呼吸），对外只暴露 `render(Snapshot, &Palette, Instant) → Icon`

- 渲染流程：更新动画状态 → 计算插值后的灌注色与全局 alpha → 生成任务栏厚度等尺寸的 RGBA 像素 → 构造 Icon

- **格阵规划**（纯函数 `plan`）：由快照推导 4 格视觉规格（base 底色 + fill 灌注），是渲染层唯一的语义决策点；待机恒为四格空心（无 completed 分支，零特殊场景）

- **像素布局**：透明背景 + 2×2 格阵；内容层先绘（底色整格实心 → 灌注底部高度 = 进度，均限于 inset 1px 内区）→ 结构层后绘（1px 空心边框**永存**，不被任何填充吞没，§4.2 边框永存不变量）

- **动画状态机**：阶段边界探测（stage_seq 变化）→ 触发 2.5s 脉冲；暂停进入 → 启动 12s 呼吸；色相变化 → 启动 0.6s lerp 过渡

- **帧率协商**：`needs_continuous_render()` 判断是否有进行中动画（过渡/脉冲/呼吸）；`needs_fast_frames()` 判断是否需要高帧率（过渡+脉冲用 50ms，呼吸用常规 250ms）

- 异常自动重绘、`reset()` 复位全部动画状态；渲染失败静默降级，无报错弹窗

- **应用图标资产嵌入**（`build.rs` + winres）：exe 图标为用户手工设计的 `Winmato.ico` 静态品牌资产（多尺寸整帧）；程序化生成器已退役——离散帧在任意显示尺寸下的重采样会丢失细线特征；托盘实时图标仍由 `icon` 模块纯函数渲染

### 6\.3 色彩操作模块（colors.rs——纯计算）

- `Rgb` 结构体：RGB 三通道、hex 解析（`#RRGGBB` / `RRGGBB`，非法返回 None）、线性插值（lerp，用于阶段切换平滑过渡）

- `Palette` 结构体：三阶段配色（focus / short_break / long_break）+ 待机轮廓色（idle_outline）

- 出厂默认配色与配置回退共用同一常量，杜绝两处字面量漂移

- 零系统依赖，纯计算，可独立单元测试

### 6\.4 薄主线模块（main.rs——粘合层）

- 薄主线只做粘合：单实例守卫 → 加载配置 → 隐藏宿主窗口 + 消息循环 → 托盘图标（左键启停 / 右键退出）→ 定时驱动周期状态机 → 按快照渲染图标

- **单实例守卫**：`CreateMutexW` 命名互斥量，`ERROR_ALREADY_EXISTS` 时静默退出；`GetLastError` 必须在 `CreateMutexW` 后立即检查（中间任何调用会覆盖 LastError）

- **隐藏宿主窗口**：仅作为消息循环载体，用户永不可见（`WINDOW_STYLE(0)` + 零尺寸）

- **托盘图标**：左键 = 启停切换，右键 = 菜单（仅退出）；初始图标 = 待机态（四格空心灰色轮廓）；`with_menu_on_left_click(false)` 确保左键不弹菜单

- **状态 tooltip**（零视觉成本信息通道，二态）：常规 =「左键启停 / 右键退出」；待机 + 完成标记 =「本轮已完成 · 左键启停 / 右键退出」；仅在状态翻转时更新（缓存去重，避免重复 FFI）。暂停态不新增 tooltip 文案——暂停信息由 ❚❚ 符号 + 降亮 + 呼吸的视觉通道承载

- **图标提升**（`promote_tray_icon`）：在 `Shell_NotifyIconW(NIM_ADD)` 后立即遍历注册表 `NotifyIconSettings` 子键，按 `ExecutablePath` 匹配当前进程，将 `IsPromoted` 置 1；失败静默降级（§7）

- **定时心跳**：常规 250ms（TICK_MS）驱动计时与进度；过渡/脉冲等短动画期提高到 50ms（TICK_FAST_MS）保证平滑；12s 慢呼吸用常规帧率即可。仅在间隔实际变化时才调用 `SetTimer`，避免重复重置丢帧

- **退出处理**：`shutdown()` 复位渲染器到待机图标后退出，不留残迹（§3.2 / §7）

- **DPI 感知**：`SetProcessDpiAwarenessContext(PER_MONITOR_AWARE_V2)`，保证托盘图标在任意 DPI 下清晰

### 6\.5 配置加载模块（config.rs——只读加载）

- 只读加载 `%APPDATA%\Winmato\config.json`，无写入、无修改 UI、不写回

- 配置缺失、损坏、格式错误、字段非法时，静默回退出厂默认参数

- **配置单位为秒**（出厂默认 25min/5min/20min 即 1500s/300s/1200s），合法区间 1..=36000 秒（1 秒 ~ 10 小时），越界回退默认；秒级配置便于开发者用 25s 等短时长快速验证完整大周期

- 配置项：`durations`（focus / short_break / long_break，秒）、`colors`（focus / short_break / long_break，hex 字符串）

- 出厂默认时长为全局唯一事实来源常量，程序默认与配置解析回退共用，杜绝两处字面量漂移

- 不暴露任何配置入口，隔离普通用户与高级配置

## 7\. 边界异常处理规范（优雅降级原则）

所有系统级异常，优先「静默修复、优雅降级」，绝对禁止弹窗报错、崩溃、强制退出、干扰用户专注：

- 单实例冲突：静默退出第二实例，不报错

- 配置文件异常（缺失/损坏/格式错误/字段非法/越界）：静默恢复默认配置，无提示、无报错、不写回

- 零时长配置：状态机兜底不 panic、不除零（配置层已拦截，状态机再兜底）

- 图标提升失败（注册表不可写/路径不匹配）：静默降级，图标留在溢出区仍可用，不报错

- 任务栏几何查询失败（`Shell_TrayWnd` 缺失/矩形异常/自动隐藏厚度 < 16px）：静默回退 SM_CXSMICON 尺寸，渲染与交互不受影响

- 单次 tick 跨越多阶段（系统休眠恢复）：循环结算到位，刻点与边界序号同步跳过，不丢状态

- 渲染异常：静默降级，无报错弹窗；`Icon::from_rgba` 失败由 `expect` 兜底（像素缓冲尺寸恒定，不可达路径）

- 进程启动：托盘图标初始即为待机态，无上次退出残迹可清理（T 方案不染色系统元素，无残留风险）

- 正常退出：`shutdown()` 复位渲染器、渲染待机图标后退出，不留残迹

## 8\. 强制技术栈（Rust 原生，轻量化）

固定技术栈，禁止替换为 Electron、Tauri 等重型框架，保障低内存、低 CPU、无依赖、启动极速：

- 核心语言：Rust（edition 2021）

- 系统 API：windows-rs 0.58（原生 Windows 接口调用：窗口、消息循环、互斥量、注册表、DPI、HiDpi）

- 托盘功能：tray-icon 0.19（极简托盘图标 + 菜单，唯一可视化表面载体）

- 配置解析：serde + serde_json（本地轻量化配置）

- **不使用**：softbuffer、SetWindowCompositionAttribute、分层窗口；不持续做任务栏几何跟踪——仅启动时只读一次 `Shell_TrayWnd` 矩形用于画布定尺寸，失败回退 SM_CXSMICON

- Release profile：opt-level 2 + LTO，产物约 0.8MB（含 7 档应用图标资源），极致轻量

## 9\. 最终产品验收标准（AI 开发校验依据）

全部满足即为合格，任意一条不满足即为不合格：

1. 全程无任何文字、数字、弹窗、通知、音效，纯环境视觉反馈

2. 用户仅有一种交互：左键点击系统托盘图标启停/暂停/继续，右键仅退出，无其他操作

3. 托盘图标为唯一可视化表面：画布边长 = 任务栏厚度 − 8px（启动时只读一次，底/顶/侧任务栏方向无关，失败回退 SM_CXSMICON），其上 2×2 格阵，四格 ≡ 四个专注番茄，格位空间编码番茄序号，绝不显示数字

4. 状态流转精准，计时稳定：专注 N 时格 1..N−1 实心 + 第 N 格底部灌注专注色；短休 N 时格 1..N 实心 + 第 N 格灌注短休色；长休时 4 格全实心 + 第 4 格灌注长休色；灌注高度 = 当前阶段进度；每格 1px 边框永存，实心/灌注仅画 inset 内区、不被填充吞没

5. 动画按规范触发：阶段切换 0.6s 色相 lerp 过渡、2.5s 边界脉冲（+15% 明度）、暂停 50% 降亮 + 恒满不透明阶段色 ❚❚ + 12s ±10% 慢呼吸；待机复位全部动画状态；周期结束（自然走完或长休暂停后收束）回归四格空心待填充待机 + tooltip「本轮已完成」，新周期启动即清除完成标记

6. 帧率按需协商：常规 250ms，过渡/脉冲期 50ms，呼吸用常规帧率；仅在间隔变化时才 SetTimer

7. 图标提升静默生效：Windows 11 下注册表 IsPromoted=1 将图标提升到可见区，失败静默降级

8. 所有系统边界异常自动适配、静默修复，零弹窗报错

9. 程序极致轻量化，后台低驻留、低 CPU、低内存占用，release 产物约 0.8MB（含 7 档图标资源）

10. 严格无功能蠕变，所有禁止功能均未开发；不染色、不叠加、不遮挡任何系统元素

11. 完全符合深模块浅接口、极简环境式、专注优先的核心设计哲学

12. 46 项单元测试全绿、clippy 零警告
