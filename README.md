# Barmato

[![CI](https://github.com/31i45/Barmato/actions/workflows/ci.yml/badge.svg)](https://github.com/31i45/Barmato/actions/workflows/ci.yml)

> Bar + Tomato — 极简环境式番茄钟 for Windows

Barmato 在任务栏上方渲染一条 5px 色彩细条，用颜色和进度提供无干扰的番茄周期环境反馈。没有弹窗、没有数字、没有声音——仅靠余光感知当前处于专注还是休息。

## 特性

- **纯环境感知**：5px 细条 + 低饱和配色 + 进度填充 + 发光边缘，余光即可感知
- **阶段进度 + 几何刻点**：细条整条 = 当前阶段时长；4 枚刻点以空间模式表达第 N 个专注番茄，无数字
- **边界脉冲与暂停呼吸**：阶段切换瞬间整条 2.5s 慢脉冲一次；暂停时降亮 40% 并叠加 12s 慢呼吸
- **托盘状态镜像**：托盘圆点随阶段换色（绿/青/蓝），暂停变空心，待机为暗灰圆点
- **极简交互**：左键点击托盘图标启停切换，右键退出，仅此而已
- **零干扰**：无弹窗、无通知、无音效、无统计、无设置窗口
- **优雅降级**：资源管理器重启自动重建，配置缺失静默回退默认值
- **极致轻量**：纯 Rust 原生，Release 构建约 460KB，待机时停止一切绘制

## 快速开始

### 下载（推荐）

前往 [Releases](https://github.com/31i45/Barmato/releases) 下载最新版，两种格式任选：

- `barmato-vX.Y.Z-x86_64-windows.exe` — 单文件即下即用（浏览器可能提示"不常见下载"，选择保留即可）
- `barmato-vX.Y.Z-x86_64-windows.zip` — 压缩包，下载拦截风险最低

解压（如选 zip）后直接运行 `barmato.exe`：单文件、零安装、零依赖。

### 构建

```bash
cargo build --release
```

可执行文件位于 `target/release/barmato.exe`。

### 使用

1. 双击 `barmato.exe` 启动（待机时托盘为暗灰小圆点，低存在感但恒可点击）
2. **左键点击**托盘图标 → 启动番茄周期（图标变为当前阶段色相圆点）
3. 再次左键 → 暂停（图标变空心圆环）；再左键 → 继续
4. **右键点击**托盘图标 → 退出

### 配置（可选）

Barmato 无需任何配置即可使用，默认时长为标准番茄钟（25/5/20 分钟）。

高级用户可创建 `%APPDATA%\Barmato\config.json` 自定义时长和配色：

```json
{
  "durations": {
    "focus": 1500,
    "short_break": 300,
    "long_break": 1200
  },
  "colors": {
    "focus": "#3A6B4C",
    "short_break": "#59A8A6",
    "long_break": "#6585B4"
  },
  "render_all_monitors": false
}
```

时长单位为秒。配置文件缺失或格式错误时静默回退默认值。

## 视觉设计

| 阶段 | 颜色 | 含义 |
|---|---|---|
| Focus | 深绿 `#3A6B4C` | 深度专注中 |
| Short Break | 薄荷青 `#59A8A6` | 短暂休息 |
| Long Break | 浅蓝 `#6585B4` | 长休息，周期将结束 |
| 暂停 | 原色相降亮 40% + 12s 慢呼吸 | 时间冻结 |

细条渲染规则：
- 底色铺满整条，进度用同色相提亮色从左至右叠加（整条 = 当前阶段时长）
- 4 枚 2×2 几何刻点均匀分布，前 N 枚亮起表示第 N 个专注番茄（纯空间编码，无数字）
- 进度前沿有 8px 发光带（更亮色相），标记当前位置
- 阶段切换时 0.6 秒平滑色彩过渡 + 2.5 秒边界脉冲一次，无突变

## 架构

```
main.rs      薄主线：消息循环 + 托盘事件 + 定时驱动
cycle.rs     周期状态机：纯业务逻辑，零 Windows API 依赖
overlay.rs   渲染层：分层透明窗口 + softbuffer 软件光栅化
taskbar.rs   几何检测：定位任务栏句柄与矩形
colors.rs    色彩模块：RGB/HSL 运算、配色、插值
config.rs    配置加载：只读 JSON，静默回退
```

设计准则遵循《软件设计的哲学（第二版）》：深模块浅接口、最小化状态、围绕不变量设计、消除特殊场景。

## 技术栈

- **Rust** + **windows-rs 0.58** — 原生 Windows API
- **softbuffer 0.4** — 软件光栅化，无 GPU 依赖
- **tray-icon 0.19** — 系统托盘
- **serde / serde_json** — 轻量配置解析
